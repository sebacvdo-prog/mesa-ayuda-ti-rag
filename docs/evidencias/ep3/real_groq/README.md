# Groq real EP3 — Pendiente

No se ejecutó Groq para desarrollar ni preparar la publicación de EP3. No hay
latencias, consumo de tokens ni calidad real EP3 acreditados. El origen `real`
del dashboard permite observar futuras ejecuciones; su existencia no prueba una.

El [cierre real de EP2 del 22 de octubre de 2026](../../ep2_etapa4_cierre_tecnico.md)
es histórico y corresponde a otro estado de código. No se suma a la evaluación
simulada EP3 ni valida la instrumentación EP3 ante el proveedor.

La [guía](../../../ep3_guia_completa.md#pendiente-de-ejecución-real--groq)
explica cómo preparar una futura ejecución autorizada con entradas sintéticas,
sin transcripciones, con clave HMAC dedicada y respetando confirmaciones humanas.
Antes de publicar una nueva evidencia, revisar sus campos y conservar el origen,
fecha, configuración, tamaño de muestra y límites realmente observados.
