# Capturas del dashboard — Pendientes

No hay imágenes de EP3 en esta entrega. Las figuras PNG/SVG de `docs/figuras/`
son diagramas EP2 preexistentes, no capturas del dashboard EP3. Fueron revisadas
visualmente y los PNG no incluyen metadatos textuales ni EXIF.

La regresión verifica el dashboard con Streamlit AppTest: carga sin agente,
fuentes v1/v2, estados ausente/vacío, filtros y bases sin cambios. No acredita
aceptación visual manual ni genera imágenes.

Para obtener capturas reales, ejecutar la evaluación simulada y el dashboard con
los comandos del README. Seleccionar `simulada` y capturar las vistas general,
RAG/calidad, errores/reintentos y salud. Mostrar la indicación de simulación y
fecha UTC. Recortar barra de direcciones, terminal y explorador; ocultar rutas
locales, referencias de sesión, identificadores innecesarios y cualquier secreto.
Revisar también los metadatos antes de agregar las imágenes. No recrear una
pantalla ni presentar una imagen generada como evidencia de ejecución.
